# 上游来源与本项目改动

本项目是基于 [jeremylongshore/cad-ai-agent](https://github.com/jeremylongshore/cad-ai-agent)
开发的建筑 CAD 只读问答衍生项目，不是从零实现的 CAD 引擎，也不代表上游作者提供或认可本项目的教学、咨询或商业服务。

## 保留的上游基础

- 上游 Python 包名称 `cad-dxf-agent`、导入名称 `cad_dxf_agent`，源快照标记版本为 `0.12.0`。
- DXF 读取、结构化图元模型、几何与渲染能力，以及 React/FastAPI 基础。
- 部分上游 CLI、桌面、编辑、分析实现和后端回归测试仍保留，以维护依赖与来源关系。
- 上游 [Apache-2.0 许可证](../LICENSE) 保持原文。源快照未附带独立 `NOTICE` 文件；本仓库 `NOTICE` 是衍生项目增加的来源说明。

原始输入为本地源快照，没有 `.git` 历史，所以本次无法证明它对应上游的哪一个提交。
版本号用于描述快照，不能替代提交哈希。最新的上游功能与文档请查阅
[上游 README](https://github.com/jeremylongshore/cad-ai-agent/blob/main/README.md)。

## 本项目增加或改造的部分

- `/local-qa` 中文只读图纸问答页面与 DeepSeek 真实 API 调用。
- 图元检索、图块实例统计、闭合轮廓面积/周长计算，以及可点击的答案依据定位。
- 独立生产入口 `web.backend.production:app`：单管理员会话、CSRF 防护、登录限速、受保护的上传/预览/下载、上传清理与健康检查。
- GNU LibreDWG 作为独立进程处理 DWG → DXF，保留版本/编码并限制转换时间和输出大小。
- 使用开源 Noto 字体的中文交互预览及 Linux 静态渲染、字形别名兼容处理。
- 合成建筑示例、对应问答/安全/转换回归测试、容器与反向代理部署配置。
- 面向独立发布的 README、配置模板、CI、发布检查和来源说明。

生产入口只开放只读问答。上游 `web.backend.main:app` 含开发与编辑接口，
不能因为源码存在就宣称这些能力已经在本项目中安全上线。源快照中的 `0.12.0`
也不是本衍生项目完成相同范围验收的声明。
