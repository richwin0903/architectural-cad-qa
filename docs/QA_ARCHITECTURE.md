# 只读 CAD 问答架构

问答由官方 `deepagents==0.7.32` 的 `create_deep_agent` 驱动，模型通过
`langchain-deepseek==1.1.1` 的 `ChatDeepSeek` 连接现有 DeepSeek 配置。
原有 `DeepSeekQA.answer` 保留为路由兼容入口，手写 HTTP 工具循环已移除。

## 请求流程

1. FastAPI 验证管理员会话、CSRF 和图纸所有权，再读取该图纸的解析上下文。
2. `cad_visual.py` 枚举全部布局，为最多 4 个非空布局生成整图预览，Model 优先。
   第一次模型请求已经包含实际整图，不依赖模型自行检索第一页图元。
3. Deep Agents 可规划步骤，调用只读工具检索、统计、量取或放大区域。
   局部视图从矢量记录重新渲染，坐标以每个布局的整图左上角为原点，取值 0–1。
   总计最多 10 张视图；未预览的非空布局在结果中明确提醒。
4. DeepSeek 同时收到结构化数据和真实预览。图像用内联 PNG 放入 user 消息，
   不放入 tool 消息，不上传至 Files API。原始 CAD 文件不发送。
   `CAD_VISION_ENABLED=false` 只关闭保留的上游 Gemini 管线；本问答链路使用 DeepSeek 图像输入，
   不受该旧开关控制，界面会明确告知发送预览图。
5. 返回原有前端响应格式，并添加 `engine: deepagents`。图元引用须在当前请求中实际查询过；
   视图引用须对应已渲染的 ID 和世界坐标范围。不存在的引用剔除并提示复核。

## 工具与边界

| 工具 | 依据与范围 |
| --- | --- |
| drawing_layouts | 全部布局及整图覆盖状态，包括空布局 |
| render_drawing_view | 指定布局的整图/局部矢量预览，无路径或 URL 参数 |
| query_entities | 分页查询顶层图元及属性，附全量匹配数 |
| count_entities | 完整筛选范围的确定性统计，默认 Model |
| measure_contours | 对源 DXF 核验闭合直边轮廓或圆，单位明确才换算 |
| write_todos | 本轮临时检查计划 |

只读工具与计划工具采用白名单。Deep Agents 的通用文件、终端和委派工具不开放；
即使模型编造调用，也会在执行前拒绝。后端使用无宿主机文件访问能力的 StateBackend，
不设置 checkpointer、store 或跨用户持久记忆。关闭自动摘要模型调用和 LangSmith 追踪。
每轮最多 6 次模型请求、每次响应最多 6 次工具调用，单请求累计最多 24 次工具调用；
路由保留 180 秒超时，模型 SDK 不自动重试。错误不回显上游响应体或密钥。

## 预览与回答限制

- 缺失定义的图块引用在内存渲染副本中跳过并提示；不修改上传文件或计数依据。
- 批量绘制相邻线段，保留线宽、颜色和绘制顺序；局部渲染复用请求内的矢量记录。
- 字体仍使用仓库中 OFL 许可的 Noto Sans SC。外部栅格图片只显示代理边框。
- 视觉可判断图种和位置，读不清的图名、楼层、朝向不得猜测。原生文字查询为零不代表
  块内也没有文字；文字也可能被炸成线段。图块数量不等于真实门窗数量。
- 几何量取使用确定性工具，不用图片估算平方米；图纸单位、真实房间边界仍需人工核验。
- 交互定位目前仅支持 Model。纸空间视图可以作为依据列出，但不显示错误的 Model 定位按钮。
- 原始问题、图纸文字和历史对话均作为数据处理。历史答案不是本轮已验证事实。

## 回归

离线测试用合成多视图 DXF 检查左右区域、其他布局、裁剪定位、真实图片请求协议、
缺失图块容错、引用校验、危险工具拒绝和调用预算；既有计数、量取、鉴权测试继续保留。
真实工程图及其转换文件、截图、回答记录只用于私有本地验收，不进入仓库。
