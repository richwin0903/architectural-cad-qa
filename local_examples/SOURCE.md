# 合成示例来源

这些文件是为本原型构造的合成几何与问答验收样例，不是客户图纸或真实工程资料。
示例与项目自有文档按本仓库的 [Apache-2.0](../LICENSE) 条款分发。

| 文件 | 来源和用途 | SHA-256 |
| --- | --- | --- |
| `architectural-demo.dxf` | 本地原型构造的 DXF 场景；包含简化房间、门窗图块与中文标签 | `33661412430f390a04a9dfd830c993d3fc78501b2305e26f763c6c3c24d5eeb6` |
| `architectural-demo.dwg` | 本项目的 [C 生成器](../scripts/create-dwg-fixture.c) 通过 GNU LibreDWG 0.14 API 生成的 DWG 2000，GBK 中文 | `d39bfaced9230b18a109754173eb69bd3cf0f154cc979dfd9fd5d9964076a3ef` |
| `expected.json` | 对 DXF 示例预设几何结果的描述，含 DXF 对应的图元句柄 | — |

两份图纸用于测试同类核心问题，但不是逐对象相同的二进制/文本副本；
DWG 图元句柄、窗口等对象集合可能不同，不能把 `expected.json` 的 DXF 句柄套用到 DWG。
两者的验收共同项为 M0921 门图块实例 2 个、会议室闭合轮廓面积 16 平方米、周长 16 米。
这些是预设闭合边界的几何结果，不代表真实建筑净面积、施工口径或完整建筑语义识别。

生成器的构建说明在文件头部。该小程序调用 GPL 的 LibreDWG C API；若分发其链接后的
可执行程序，须连同 LibreDWG 按相应 GPL 要求处理。仓库只保留生成器源文件和生成的
原创几何样例，不携带这个生成器的可执行程序。
